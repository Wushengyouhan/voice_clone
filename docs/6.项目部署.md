# 6. 项目部署（Docker + 阿里云 ACR + GitHub Actions）

## 目标

向 **`main`** 分支 **push** 后，由 GitHub Actions **构建 Docker 镜像**并推送到 **阿里云容器镜像服务 ACR**，标签固定为 **`latest`**（单架构 **linux/amd64**）。

## 镜像地址示例

完整仓库路径（与 ACR 控制台一致）：

```text
crpi-wzkmn99umn8syi28.cn-shanghai.personal.cr.aliyuncs.com/wushengyouhan/voice_clone:latest
```

其中：

- **Registry（登录地址）**：`crpi-wzkmn99umn8syi28.cn-shanghai.personal.cr.aliyuncs.com`
- **命名空间**：`wushengyouhan`
- **仓库名**：`voice_clone`

## GitHub Secrets

在仓库 **Settings → Secrets and variables → Actions** 中配置：

| Secret 名称 | 说明 |
| --- | --- |
| `ACR_REGISTRY` | Registry 地址，**不要**带 `https://`，例如：`crpi-wzkmn99umn8syi28.cn-shanghai.personal.cr.aliyuncs.com` |
| `ACR_USERNAME` | 阿里云账号或 RAM 用户名（与 `docker login` 一致） |
| `ACR_PASSWORD` | 镜像仓库登录密码（控制台「访问凭证」或独立密码） |
| `ACR_NAMESPACE` | 命名空间，例如：`wushengyouhan` |
| `ACR_REPOSITORY` | 镜像仓库名，例如：`voice_clone` |

最终推送标签为：

```text
${ACR_REGISTRY}/${ACR_NAMESPACE}/${ACR_REPOSITORY}:latest
```

## 工作流文件

- `.github/workflows/build-push-acr.yml`：`main` push 时构建并推送。

## Dockerfile

- 项目根目录 **`Dockerfile`**
- Next.js **`output: "standalone"`**（见 `next.config.ts`），运行时监听 **`3000`**
- 容器启动后需在运行环境注入业务变量（**不要**打进镜像）：`DATABASE_URL`、`ALIYUN_DASHSCOPE_API_KEY`、OSS 相关等，与本地 `.env` 一致

### 运行示例（仅说明，按你实际编排替换）

```bash
docker run -d -p 3000:3000 \
  -e DATABASE_URL="mysql://..." \
  -e ALIYUN_DASHSCOPE_API_KEY="sk-..." \
  -e OSS_REGION="..." \
  -e OSS_ACCESS_KEY_ID="..." \
  -e OSS_ACCESS_KEY_SECRET="..." \
  -e OSS_BUCKET="..." \
  -e OSS_ENDPOINT="..." \
  your-registry/your-ns/your-repo:latest
```

数据库迁移请在部署流程中单独执行（例如 `prisma migrate deploy`），不要依赖镜像内交互式命令。

## 服务器 docker-compose

项目根目录提供 **`docker-compose.yml`**，与 **`Dockerfile` 同级**。

1. 在服务器建目录，放入 **`docker-compose.yml`**，并复制 **`.env`**（内容参考仓库 `.env.example`，填真实密钥）。
2. 若镜像在 ACR 私有仓库，先登录（地址与账号密码同 ACR 控制台）：

   ```bash
   docker login crpi-wzkmn99umn8syi28.cn-shanghai.personal.cr.aliyuncs.com
   ```

3. 启动：

   ```bash
   docker compose pull
   docker compose up -d
   ```

4. 查看日志：`docker compose logs -f`

默认映射 **`3000:3000`**。若数据库在**本机宿主机**的 `127.0.0.1`，容器内不能直接访问，可二选一：  
- `DATABASE_URL` 里主机改为**宿主机内网 IP**；或  
- 解开 `docker-compose.yml` 里 **`extra_hosts: host.docker.internal:host-gateway`**，并把 `DATABASE_URL` 主机写成 **`host.docker.internal`**（需 Docker Compose 2.1+）。

更换镜像地址时，直接编辑 `docker-compose.yml` 中的 **`image:`** 一行即可。

## 本地构建自检

```bash
docker build -t voice-clone:local .
docker run --rm -p 3000:3000 -e DATABASE_URL="mysql://..." voice-clone:local
```
