1. 我想实现一个可以一个合成音色的H5应用，支持移动端和桌面端。
2. 主要有两块功能
- 2.1 上传一段音频，然后创建音色。
- 2.2 选择已有音色，输入文字，合成语音。可以预览和下载。
3. 技术栈
- **框架**: Next.js 16 (App Router)
- **UI 库**: React 19
- **样式**: Tailwind CSS 4
- **组件库**: shadcn/ui
- **状态管理**: Zustand
- **表单处理**: React Hook Form + Zod
- **数据库**: MySQL + Prisma ORM

4. 页面设计，组件设计。多多参考项目里的skills。页面主要用shadcnui
5. 创建音色和合成语音主要用阿里的这个，下面是参考文档。
https://help.aliyun.com/zh/model-studio/text-to-speech?spm=a2c4g.11186623.help-menu-2400256.d_0_4_2_0.337d6cc5b23xrz&scm=20140722.H_2842586._.OR_help-T_cn~zh-V_1
我希望完全通过nextjs实现，所以你看看能不能行。

6. 因为合成需要用到公网的音频url，所以上传音频就保存到oss。具体保存在哪个目录，你可以再设计。
