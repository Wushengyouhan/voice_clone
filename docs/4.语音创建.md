# 4. 语音创建（音色复刻）

> 文档索引：`1.项目描述` → `2.数据库设计` → `3.数据库简表流程` → **本文** → `5.语音合成`

## 流程（端到端）

1. 用户在首页填写**音色名称**，选择 **WAV / MP3 / M4A** 样本（≤10MB）。
2. 浏览器 **`POST /api/voices`**（`multipart/form-data`）。
3. 服务端将文件写入 **OSS** `voice-samples/…`，得到公网 **`sampleUrl`**（需百炼能匿名下载，见环境变量）。
4. 服务端请求 **百炼** `voice-enrollment` / `create_voice`，传入 `sampleUrl`，得到 **`voice_id`**。
5. 写入 MySQL 表 **`Voice`**：`name`、`sampleUrl`、`voiceId`（阿里 id）。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/voices` | 创建音色。表单字段：`name`（string）、`file`（File）。成功 `200`：`{ voice: { id, name, sampleUrl, voiceId, createdAt } }`。失败：`4xx/5xx` + `{ error: string }`；百炼失败时可能带 `sampleUrl` 便于排查。 |
| `GET` | `/api/voices` | 最近 50 条音色列表：`{ voices: [...] }`。 |

校验要点：`name` 1～64 字；音频 MIME 与扩展名需为 wav/mp3/m4a 一类。

## 环境变量（与本功能相关）

- `ALIYUN_DASHSCOPE_API_KEY`：百炼 API Key。
- `COSYVOICE_TARGET_MODEL`：可选，默认 `cosyvoice-v2`（须与后续合成所用模型一致）。
- `OSS_REGION` / `OSS_ACCESS_KEY_ID` / `OSS_ACCESS_KEY_SECRET` / `OSS_BUCKET` / `OSS_ENDPOINT`。
- `OSS_PUBLIC_BASE_URL`：可选，CDN 或自定义域名前缀。
- `OSS_OBJECT_ACL`：可选，默认 `public-read`；若 Bucket 关闭 ACL，可设 `private` 并在控制台为 `voice-samples/*` 配置匿名读策略。
