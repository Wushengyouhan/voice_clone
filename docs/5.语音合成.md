# 5. 语音合成（文本转语音）

> 文档索引：`1.项目描述` → `2.数据库设计` → `3.数据库简表流程` → `4.语音创建` → **本文**

## 需求摘要

- 用户选择本地已入库的**音色**（`Voice.id`），输入文本，点击合成。
- 合成结果写入表 **`Synthesis`**，并在页面上**试听**、**下载**（MP3）。

## 流程

1. 前端 `POST /api/synthesize`，JSON：`voiceId`（**本地** `Voice.id`）、`text`。
2. 服务端查库得到百炼音色 `Voice.voiceId`，用 **`COSYVOICE_TARGET_MODEL`** 调用百炼 **非流式** `SpeechSynthesizer`。
3. 从返回的临时 `audio.url` **拉取二进制**，再上传到 OSS `tts-output/…mp3`，得到长期可访问的 **`outputUrl`**（需桶/对象可读策略与创建音色一致）。
4. `prisma.synthesis.create` 写入 `voiceId`（外键指向本地 `Voice.id`）、`text`、`outputUrl`。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/synthesize` | Body：`{ "voiceId": "<Voice.id>", "text": "..." }`。成功 `200`：`{ synthesis: { id, voiceId, voiceName, text, outputUrl, createdAt } }`。 |
| `GET` | `/api/syntheses` | 最近 40 条记录，含 `voiceName`，用于「最近合成」列表。 |
| `DELETE` | `/api/syntheses/[id]` | 删除指定合成记录；若 `outputUrl` 属于当前桶/配置的公网前缀，会尝试删除 OSS 对象。 |

文本长度上限 **20000** 字符（与百炼文档一致）。

## 前端组件

| 文件 | 说明 |
| --- | --- |
| `components/voice-synthesize-form.tsx` | 拉取 `/api/voices` 下拉选音色；文本域；提交合成；展示 `<audio>` 与下载链接；`/api/syntheses` 历史列表。 |
| `app/page.tsx` | 「文本合成」区块挂载 `<VoiceSynthesizeForm />`。 |

## 服务端模块

| 文件 | 说明 |
| --- | --- |
| `lib/dashscope-tts.ts` | `POST …/SpeechSynthesizer`，解析 `output.audio.url`。 |
| `lib/oss.ts` | `uploadBinaryToOss` 写入合成 MP3（与样本共用 `OSS_OBJECT_ACL` 等逻辑时可配）。 |

## 环境变量

与 `4.语音创建` 共用 **`ALIYUN_DASHSCOPE_API_KEY`**、**`COSYVOICE_TARGET_MODEL`**、OSS 相关变量。**合成所用 `model` 必须与创建该音色时一致。**
