# 数据库简表流程（MySQL + Prisma）

## 1. 目标

在现有 MySQL 服务器上，新建本项目独立数据库 `voice_clone`，并用 Prisma 创建当前最小表结构。

## 2. 前置条件

- 已有可用 MySQL 实例（你当前是 Docker 部署）
- 已知连接信息：主机、端口、用户名、密码
- 本地项目已配置好 Prisma（当前项目已完成）

## 3. 创建数据库

先连接 MySQL：

```bash
# 连接远程 MySQL；这里输入的是 MySQL 的 root 账号密码（不是服务器登录密码）
mysql -h 139.196.30.138 -P 3306 -u root -p
```

登录后执行：

```sql
-- 创建本项目独立数据库（已存在则跳过）；utf8mb4 用于完整支持中文与表情
CREATE DATABASE IF NOT EXISTS voice_clone
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

如无权限，用管理员账号授权：

```sql
GRANT ALL PRIVILEGES ON *.* TO 'cc'@'%' WITH GRANT OPTION;
GRANT ALL PRIVILEGES ON *.* TO 'cc'@'localhost' WITH GRANT OPTION;
FLUSH PRIVILEGES;
```

## 4. 配置项目连接串

编辑项目根目录 `.env`：

```env
DATABASE_URL="mysql://cc:你的密码@139.196.30.138:3306/voice_clone"
```

## 5. 生成与迁移

在项目根目录执行：

```bash
npm run prisma:generate
npm run prisma:migrate -- --name init_voice_tables
```

执行成功后会在 `voice_clone` 库中创建当前表结构。

## 6. 当前简表结构（V1）

### Voice

- `id`：主键（cuid）
- `name`：音色名称
- `sampleUrl`：样本音频 URL
- `voiceId`：阿里返回音色 ID（唯一）
- `createdAt`：创建时间

### Synthesis

- `id`：主键（cuid）
- `voiceId`：关联 `Voice.id`
- `text`：合成文本
- `outputUrl`：输出音频 URL
- `durationMs`：时长（毫秒，可空）
- `createdAt`：创建时间
- `updatedAt`：更新时间

## 7. 验证

- `npx prisma studio`

## 8. 说明

- 同一个 MySQL 实例可以放多个项目数据库，互不影响。
- 建议每个项目一个独立数据库，便于迁移、备份和权限隔离。
